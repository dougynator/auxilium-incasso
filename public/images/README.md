# Logo Bestanden

Plaats hier je logo bestanden:

- `logo.png` - Hoofdlogo (aanbevolen: 300x100px of groter, PNG met transparante achtergrond)
- `logo.svg` - Vector logo (optioneel, voor betere kwaliteit)

## Formaat aanbevelingen:

- **PNG**: 300x100px of groter, transparante achtergrond
- **SVG**: Vector formaat voor beste kwaliteit op alle schermen
- **Formaat**: Horizontaal logo werkt het beste

## Hoe toe te voegen:

1. Plaats je logo bestand in deze map als `logo.png` of `logo.svg`
2. Als je beide hebt, heeft PNG prioriteit
3. Het logo wordt automatisch gebruikt in de hele applicatie

## Fallback:

Als het logo niet gevonden wordt, wordt automatisch de tekst "Auxilium Incasso" getoond.
